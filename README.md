# ClawHub Dashboard

Health Monitor Dashboard für Clowie — OpenClaw System-Status.

## Komponenten

- `health_dashboard.html` — Visual Dashboard (Traffic-Light System)
- `serve_dashboard.py` — Python HTTP Server
- `serve_dashboard.sh` — Shell Wrapper
- `health_monitor.py` — Core Checker (20+ Checks, Auto-Remediation)
- `run_health_monitor.sh` — Cron Wrapper

## Deployment

Wird via ClawHub auf Hostinger deployed.
